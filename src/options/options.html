Keyboard shortcut

Copy page as Markdown: Alt+M by default (Option+M on Mac). Change it under chrome://extensions/shortcuts (Chrome/Edge) or Add-ons Manager → gear → “Manage Extension Shortcuts” (Firefox).

Privacy

Downright makes no network requests — nothing you clip ever leaves this browser. Settings sync through your browser profile. That is the whole story, and the source code is public so you can check.
