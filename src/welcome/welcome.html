Three ways to clip

The keystroke

Press AltM anywhere. The article lands on your clipboard, ready to paste into ChatGPT, Claude, Obsidian, or a doc.

A selection

Select text first and the same keystroke — or right-click → Copy selection as Markdown — clips just that, keeping list numbering, table headers, and fences intact.

The popup

Click the toolbar icon to read the Markdown before you copy it, switch Article ↔ Full page, check the token estimate, or save it as a .md file.

You always find out what happened

Every clip raises this in the corner of the page: the leafcutter hauling it in with the token count, or a still mark and the reason it could not. Pages extensions are not allowed to run on — browser settings, the add-on stores, the PDF viewer — say so by name instead of failing silently.

Prefer it quiet? Turn the toast off in settings.

It never phones home

  • No network requests. Ever. There is no fetch, no XHR and no beacon anywhere in the code — checked mechanically in CI on every push.
  • No host permissions. Downright cannot read a page in the background. It runs on the tab you invoke it on, at the moment you invoke it.
  • Token counts are local. Estimated as ≈ chars/4, CJK-weighted. No tokenizer ever gets called.
  • Hidden text is dropped. Off-screen and sr-only content, and invisible Unicode carriers, are stripped — nothing rides into your chat unseen.

The whole permission list: activeTab, scripting, clipboardWrite, storage, contextMenus.
