Downright

No network.
No tracking.
No exceptions.

The code contains zero network calls — verified by an automated audit on every release — and the source is public on GitHub so you can check.

🔒
Can’t read pages in the background No host permissions. Downright only sees a page at the moment you press the shortcut or click the button — never before, never after.
📴
Everything happens on your machine Conversion, token estimates, downloads — all local. Nothing you clip ever leaves this browser.
🧾
Four small permissions, in plain words Run on the tab you invoke it on · write to your clipboard · remember your settings · add the right-click menu. That’s the whole list.
